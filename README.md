**Prompt:**

"Mujhe ek fully modern, professional Gym App/Website banani hai jo real gym business jaisi lage — desktop, tablet, aur mobile teeno par perfectly responsive ho.

**Overall Theme & Style:**

- Color scheme: Bold Red aur Yellow, dark/black background ke saath high-energy gym vibe create karna

- Design 2026 ka latest modern trend follow kare — clean, minimal, premium look

- Zyada text nahi, sirf impactful short lines

- Zyada pages na ho — ek smooth single-page scroll design ya max 5-6 sections

- High-quality real-looking gym/fitness images use karna (weights, training, gym interior, trainers)

- Smooth animations, hover effects, aur subtle transitions har section mein

- Rounded cards, shadows, aur modern typography

**Sections/Pages chahiye:**

1. **Hero Section**

   - Gym ka naam aur bold tagline

   - Background mein powerful gym image ya video

   - "Join Now" jaisa call-to-action button

2. **About Gym**

   - Short intro ke saath gym ki achievements (jaise "500+ Members", "10+ Trainers")

3. **Services**

   - Personal Training, Cardio, Weight Training, Yoga, Diet Plans, Group Classes — sab cards ki form mein icons ke saath

4. **Trainers Section**

   - Trainer ki photo, naam, aur specialty short cards mein

5. **Gallery**

   - Gym ki multiple achi images grid layout mein

6. **Membership Plans**

   - 3 pricing cards (Basic, Standard, Premium) — features aur price ke saath

7. **Login / Sign-up System**

   - User apna account bana sake, login kar sake

   - Simple aur secure form design

8. **Admin Panel**

   - Admin members, bookings, aur plans manage kar sake

   - Simple dashboard design

9. **Testimonials**

   - Members ke reviews cards mein

10. **Contact & Footer**

    - Location, phone, email, social media icons, aur ek short contact form

**Technical Requirements:**

- Fully mobile-responsive (hamburger menu on mobile)

- Fast loading, clean code

- Modern fonts aur icon library use karna

- Interactive buttons aur smooth scroll navigation

Overall design bilkul ek premium, trending, real gym app jaisa aur professional lagna chahiye — jo dekhte hi impress kare."
